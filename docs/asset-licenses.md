## Licensing Rules

1. **Explicit Permissions:** No copyrighted assets without an explicit open-source, permissive, or written custom license.
2. **Provenance Tracking:** Any asset added to `res://assets/` must be registered here before merging or committing.
3. **Programmer Art First:** Temporary programmer art should be used during early gameplay iterations to avoid acquiring large unused asset libraries.
4. **Code vs. Art Separation:** Code is licensed under Apache License 2.0 (see `LICENSE`); art/audio licensing is tracked separately in this ledger.
